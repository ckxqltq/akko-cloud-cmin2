## 先说说CMIN2是个什么东西

你可能听过CN2 GIA，那是电信的高端线路，号称"精品网"。联通这边对应的叫CUP或者9929。那移动呢？很长一段时间里，移动用户用海外VPS，体验就像坐绿皮火车——能到，但慢，而且晚高峰特别挤。

CMIN2是中国移动国际有限公司（CMI）推出的"国际精品网"品牌，定位跟电信CN2 GIA、联通CUP是一个级别的。它有独立的传输通道，QoS优先级更高，专门面向跨境电商、实时音视频、企业专线这些对延迟敏感的场景。

一句话：CMIN2是移动用户的高端出海专线，地位等同于电信的CN2 GIA。

市面上提供CMIN2线路的商家其实不多，出口带宽相对充裕，不像有些热门线路一到晚高峰就直接炸。这点对国内用户来说，挺关键的。

## AkkoCloud是什么来头

AkkoCloud是2019年成立的国内主机商，一开始主要做国内独立服务器，后来扩展到海外VPS。目前主打三个机房：美国圣何塞、德国法兰克福、英国伦敦，全部采用KVM架构+SSD硬盘。
